## 1. 它是什么
**bensz-paper**：入口 `packages/bensz-paper/bensz-paper.sty:5-13`（`\ProvidesPackage{bensz-paper}`，可选载入 `bensz-fonts`，`\RequirePackage{bml-core}`，别名 `\BenszPaperSetup`）；旧入口 `benszmanuscriptlatex.sty:6-9` 仅转发。核心 `bml-core.sty:93-115`： `\BenszManuscriptSetup{#1}` 先取 `template=` 载入 `profiles/bml-profile-<模板>.def`，再用同批键覆盖用户值，最后按 layout→headings→typography→floats→bibliography→review 加载 7 个模块：`bml-layout`（geometry+fancyhdr）、`bml-headings`（titlesec，`secnumdepth=0`）、`bml-typography`（fontspec/setspace/microtype/hyperref/bookmark/xurl/csquotes）、`bml-floats`（graphicx/booktabs/longtable/tabularx/multirow/caption/enumitem）、`bml-bibliography`（**强制** `biblatex[backend=biber]`）、`bml-review`（lineno）。内置 profile 3 个：`paper-sci-01`、`paper-coverletter-01`、`bensz-manu-01`（中文稿默认 `gb7714-2015`、A4、1.5 倍行距、行号开启，见 `profiles/bml-profile-*.def`）。
脚本 `scripts/manuscript_tool.py`：PDF 走 XeLaTeX→Biber→XeLaTeX→XeLaTeX；DOCX 走 Pandoc LaTeX→Markdown→HTML5+MathML→DOCX + python-docx 后处理；外部依赖 xelatex/biber/pandoc/可选 soffice（见其 1-27 行、`scripts/requirements.txt`）。安装器 `scripts/package/install.py:100-128` 写入 TEXMFHOME 并生成 Windows `bpaper.cmd`；`bml`/`bpaper` 是无后缀 **bash shim**（Windows 直接调同名 `.py`）。消费方式见 `projects/paper-sci-01/main.tex:2-8`：`\documentclass[12pt,a4paper]{article}` + `\usepackage{bensz-paper}` + `\BenszPaperSetup{template = paper-sci-01, bibliography-style = vancouver}`，正文全部 `\input{extraTex/...}`（39-50 行），citation 走 biblatex/biber。

**bensz-nsfc**：`bensz-nsfc-common.sty:1-8` 载入 `bensz-nsfc-core.sty`；`bensz-nsfc-core.sty:4-8` 用 `kvoptions` 解析 `type=general|local|young`，85-89 行载入 `profiles/bensz-nsfc-profile-<type>.def`，98-100 行载入 `templates/bensz-nsfc-<type>.tex`，96-102 行留 4 个项目覆盖钩子（`\NSFCProjectConfigBeforePackage` 等）。`templates/bensz-nsfc-general.tex` 是 405 行整体实现（中文断行、字号命令、KaiTi/Times、titlesec、thebibliography 间距、lstlisting 等）；`*-layout/typography/headings/bibliography.sty` 为保留骨架；`assets/bibtex-style/*.bst` 是 BibTeX 样式；`scripts/nsfc_project_tool.py:5,238-280` 固定四步 `xelatex→bibtex→xelatex→xelatex`。唯一消费方式：`\documentclass[12pt,UTF8,AutoFakeBold=2.5,a4paper,fontset=none]{ctexart}` + `\usepackage[type=general]{bensz-nsfc-common}`（`examples/basic-usage.tex:1-3`），项目层在 `extraTex/@config.tex` 末尾放同一行（`projects/NSFC_General/extraTex/@config.tex:428`），`.nsfc-version` 锁 `ref+commit+template_version`。

## 2. 许可
`license.txt:1-6`：`The MIT License (MIT) / Copyright © 2024 Weibin Huang`，要求 “The above copyright notice and this permission notice shall be included in all copies or substantial portions of the Software.”；两个 `package.json` 均声明 `"license": "MIT"`。**vendor/复制任何 .sty/.def/.py/.tex 子集时，必须随附 MIT 全文与该版权行**（可放 `THIRD_PARTY_NOTICES`），修改版保留声明。
边界：MIT 只覆盖其声明所辖代码。仓库 tracked 20 个字体文件（`packages/bensz-fonts/fonts/`，含 `TimesNewRoman.ttf`、`SimSun.ttf`、Adobe 四款 OTF、方正两款 TTF；`git ls-files | Select-String '\.(ttf|otf)$'` 可复现），`bensz-fonts/README.md:23-24` 自述“方正字体的使用、打包和再分发须遵守相应字体许可”。这些字体的再分发条款 **未验证**，不随 MIT 自动授权；vendor 时不要复制，只引用系统字体名。

## 3. 依赖与工具链（含实测编译）
文档要求（`README.md:174-181`）：发行版“TeX Live（推荐）或 MacTeX”，编译器“**必须使用 XeLaTeX**”，顺序 `xelatex -> bibtex -> xelatex -> xelatex`；`package.json` 声明 `texlive >=2020 + xelatex`；187 行建议 Windows 用 WSL；测试矩阵未含 MiKTeX。本机为 MiKTeX 25.12（`xelatex --version` = MiKTeX-XeTeX 4.16），xelatex/bibtex/biber/latexmk/pandoc 均在 PATH。按仓库 `validate_package.py:150-160` 的做法，在临时目录用 `TEXINPUTS` 指向包目录复现，不写仓库、不改 TEXMFHOME。

## 4. 适配性判断
**顶会论文派生（官方模板 + ccfa.yaml）：参考思路，不复用实现。** 官方 `neurips_2025.sty`/`acl.sty`/AAAI 类已自带文档类、样式与页数规则；bensz-paper 基于 `article` 自行重排 geometry/titlesec/caption/biblatex，直接叠加会与官方类抢格式。`bml-bibliography.sty:14-37` 无条件 `\RequirePackage{biblatex}`（backend=biber、默认 gb7714-2015、vancouver 分支），与多数顶会模板的 `natbib`+bibtex 流程冲突；字体 `Times New Roman`、A4、1.5 倍行距也不是会议版式。可借：`bml-core.sty:93-106` 的 “profile + 二次 `\setkeys` 覆盖” 模型、薄入口包、`extraTex` 单一正文源与 `\input` 顺序驱动 DOCX（`docs/for-developers/paper-template-standard.md:96-102`）。若坚持 vendor，需适配层拆出 biblatex/字体/标题格式，成本与自研 profile 层相当。
**中文期刊/学位场景：倾向参考，不整体复用。** 中文稿 profile（`bensz-manu-01`）的 GB/T 7714、字号间距、行号与 PDF+DOCX 双输出可用，但依赖 `biblatex-gb7714-2015` 与中文字体；学位论文应看同仓库 `bensz-thesis`（`ctexbook` 体系），bensz-paper 只覆盖 `article` 类论文。中文期刊若确需 PDF+DOCX，可先按 `paper-coverletter-01` 的 profile 思路复刻参数，不复制字体。
**bensz-nsfc：不复用（超出目标场景）。** Word 像素级对齐的 NSFC 专用实现，固定 ctexart + bibtex bst + 四遍编译（`scripts/nsfc_project_tool.py:5,238-280`），与顶会/期刊链路无交集；仅当确要做中文标书派生时再评估。

## 5. 结论（模板阶段动作）
(a) **不 vendor 整个包，也不 vendor `bensz-fonts`。** 仅当确实需要 profile 层时，才复制 `bml-core.sty` + 裁掉 biblatex 依赖的 layout/headings/typography/floats + 目标 `.def` + `bensz-paper.sty`，并在 `THIRD_PARTY_NOTICES` 附 MIT 全文与版权行；第一版建议 **零代码 vendor**。
(b) **只借鉴**：profile 键值 + 二次覆盖顺序；薄入口包；`extraTex` 单一正文源、`\input` 顺序驱动 PDF/DOCX；`.latex-cache/` 中间产物隔离、根目录只留 `main.pdf`；PDF/DOCX 分步转换——全部在 `ccfa.yaml` 工具链中重写为自有实现。
(c) **明确不采用**：`bensz-nsfc` 全部；`bensz-fonts` 及 bundled 字体；强制 biblatex 的 `bml-bibliography.sty`；`bml-headings.sty` 的全局 `secnumdepth=0`；bash shim `bml`/`bpaper`；NSFC 四遍 bibtex 链；任何直接覆盖官方顶会类样式的 geometry/titlesec 设置。

**Verdict：低—中（reference-only）。** 代码质量与分层设计值得读，直接 vendor 的收益低于耦合成本；顶会模板层应自建，最多引其 profile 思路。
**五条关键证据**：(1) `bml-core.sty:93-115` profile 载入 + 用户键二次覆盖 + 模块顺序；(2) `bml-bibliography.sty:14-37` 无条件 biblatex/biber + gb7714 默认；(3) `projects/paper-sci-01/main.tex:2-8` 与 `packages/bensz-nsfc/examples/basic-usage.tex:1-3` 两种消费契约；(4) 本机编译：paper `min.log:170-179` 缺 `setspace.sty`，NSFC 首跑缺 `wasysym.sty` 且 installer `FATAL ... GUI framework cannot be initialized`；(5) `license.txt:1-6` + tracked 字体清单 + `bensz-fonts/README.md:23-24`。
**建议动作**：(1) 模板层采用“官方顶会类 + 自有 profile 元数据”，禁止把 bensz-paper 直接叠到 NeurIPS/ICML/ACL/AAAI 类上，`ccfa.yaml` 只记录模板标识与校验项；(2) 中文期刊派生先起草 20 行 profile 转换表（字号/行距/标题/引用格式），再决定是否复制 `bml-core` 子集，复制即附 MIT 声明；(3) 在干净 TeX Live（非 MiKTeX）环境跑一次上游 `validate_package.py` 全量校验留档，MiKTeX 侧需先补齐 setspace/tabu/biblatex-gb7714-2015 再复测，现结论标“环境未满足”；(4) 本备忘为只读评估：未改动我们的仓库；MiKTeX 侧仅有 on-the-fly 探测，两例均未产出 PDF。
