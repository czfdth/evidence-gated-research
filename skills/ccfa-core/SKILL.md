# CCFA Core

Run `ccfa doctor`, `ccfa readiness`, and `ccfa change_log` from the installed
`ccfa-research-workflow` package. Keep authoritative claims in
`data/claim-registry.yaml`; model output is advisory unless a human gate says
otherwise.
